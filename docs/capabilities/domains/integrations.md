# Integrations

This domain will connect Kordex meaning to external sources and consumers,
including repositories, agent tools and APIs. Its leaves are currently design
directions without bound executable owners.

- **D1 (P4):** declare source/interpretation/write ownership for every adapter.
- **D2 (P2/P3):** outputs distinguish observations, interpretations and proposals.
- **D3 (P3/G3):** context access is separate from execution permission; runtime
  enforcement must exist before claiming restricted actions are actually blocked.
- **D4 (P3/G4):** dependency impacts are identified as observed, derived or unknown.
  Free-form diagram edges do not establish runtime dependency facts.
