# Context

This domain supplies useful, bounded interpretation context to a consumer while
preserving scope and evidence. It includes context assembly and derived user-fit
signals; it does not own canonical writes or a general agent runtime.

- **D1 (P1/G1):** context identifies its source scope and relevant composition.
- **D2 (P2):** derived signals remain distinguishable from observed evidence and
  accepted facts. Personal fit is not authorization or model training.
- **D3 (P2/P3):** assembly consumes explicit inputs; retrieval, IO and ranking
  policies have named owners rather than hidden access inside pure assembly.
- **D4 (P3/G4):** bounds and exclusions are explicit. A limited context pack
  must not be represented as complete knowledge of all relevant dependencies.
